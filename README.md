# Ghaith Portfolio

Personal portfolio website built with Vite, React, and Tailwind CSS.

## Overview

This project is a modern single-page portfolio showcasing work, experience, and contact information. It includes reusable React components and Tailwind CSS styling for a responsive design.

## Features

- Hero section with introduction
- About section
- Experience timeline
- Projects showcase
- Contact form
- Responsive navbar and footer

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Project Structure

- `src/` – source files
- `src/components/` – shared UI components
- `src/sections/` – page sections
- `public/` – static assets

## Notes

Update the content and styling to reflect your latest projects, experience, and personal branding.
