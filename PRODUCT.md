# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters and hiring managers evaluating Ghaith Aroudaki for frontend development roles.

## Product Purpose

The portfolio helps visitors quickly understand Ghaith's frontend capability, technical range, project experience, and readiness for professional opportunities. Success is a qualified contact or follow-up conversation about a frontend role.

## Positioning

An engineer-led portfolio that pairs practical frontend craft with a thoughtful product and systems mindset.

## Operating Context

Visitors typically scan the site during a hiring or sourcing workflow, often on desktop first and mobile second. They need a fast, credible overview before deciding whether to contact Ghaith or inspect a project.

## Capabilities and Constraints

- Single-page portfolio with anchor navigation.
- Must remain responsive and accessible across desktop and mobile web.
- Must preserve real project links and contact links already present in the repository.
- Projects without a live URL must not render empty navigation targets.
- Technical skills are grouped into Frontend, Backend & Databases, and Developer Tools & Platforms.
- Security-related tools and skills are excluded from the Technical Skills section.

## Brand Commitments

- Keep the name Ghaith Aroudaki and the existing personal contact destinations.
- Voice should be clear, capable, warm, and professional rather than overhyped.
- Preserve the truthful project, education, experience, and SYNC'26 Hackathon content.

## Evidence on Hand

- Live project links and GitHub repositories in `src/sections/Projects.jsx`.
- Education, experience, and location details in the existing portfolio sections.
- Existing deployed portfolio at `https://www.ghaitharoudaki.me/`.

## Product Principles

- Make credibility scannable.
- Show work before making claims.
- Prefer clarity over decoration.
- Make every interaction intentional.

## Accessibility & Inclusion

Use semantic HTML, visible keyboard focus, readable contrast, descriptive link labels, and layouts that remain usable on narrow screens.
