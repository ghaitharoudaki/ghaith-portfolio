## Tokens

- Black: `#050607`
- Graphite surface: `#0d1014`
- Electric blue: `#4d8dff`
- Saucer red: `#ff5b52`
- Beam violet: `#7664c5`
- White: `#f5f7fa`
- Display/type family: system UI / SF Pro fallback
- Metadata family: IBM Plex Mono

## Composition

- Large section index and title on the left, content field on the right.
- A still black field and a sculptural 3D UFO create a focused visual anchor without motion noise; pointer movement tilts the object to reveal depth.
- Projects use a single editorial list with real destinations and no empty links.
- Mobile collapses each two-column rhythm into a readable vertical inspection path.

## Interaction

- One restrained reveal language for entering content.
- Links are explicit text actions with directional arrows.
- Theme toggle is always available in the first viewport.
- Email copy action provides immediate confirmation with a check state.
